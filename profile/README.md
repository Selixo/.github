---

## How we work

We believe good software should be:

* **Simple** — without unnecessary complexity
* **Reliable** — built to work consistently
* **Scalable** — ready to grow with the project
* **Maintainable** — designed for long-term development

We choose technologies based on the problem rather than forcing every project into the same stack.

## Featured projects

### Terrai

A SaaS application for generating comprehensive reports on building plots in Poland.

The system aggregates data from public sources, processes the information and uses AI to generate a structured report with maps and supporting data.

**TypeScript** · **SaaS** · **AI** · **Data Processing**

---

### Luxury Nails

A full-stack booking platform designed for a real-world beauty business.

The system replaces manual, phone-based scheduling with an online booking experience for both customers and the business owner.

**TypeScript** · **Web Application** · **Booking System**
